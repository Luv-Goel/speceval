# Security Policy

## Supported Versions

Only the latest major version of SpecEval receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them to the maintainers privately via GitHub Security Advisories or via email if provided on the profile. You should receive a response within 48 hours. If the issue is confirmed as a vulnerability, we will open a Security Advisory and provide a timeline for the fix.
